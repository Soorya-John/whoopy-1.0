# nRF24 control protocol v1

Both ends use the shared `shared/protocol/radio_protocol.h` encoder, not raw structs. Packets are exactly 32 bytes, little-endian. Bytes: 0 type (1 control), 1 version (1), 2–3 sequence, 4–5 roll, 6–7 pitch, 8–9 yaw, 10–11 throttle, 12 flags (bit0 arm, bit1 explicit disarm, bit2 acro), 13 reserved zero, 14–17 transmitter milliseconds, 18–29 reserved zero, 30–31 CRC-16/CCITT-FALSE over bytes 0–29. Axes and throttle are unsigned 0–1000; centered axes use 500, throttle uses 0 as minimum. Invalid reserved bits, conflicting arm/disarm flags, ranges, type, size, version or CRC are rejected.

Default radio settings: address `WHOPY` (5 bytes), channel 76, 1 Mbps, 32-byte payload, hardware auto-ack enabled with bounded retries. The receiver accepts only modulo-16-bit newer sequence numbers. Sender timestamp is diagnostic only; freshness is enforced by local receive age. Defaults transmit 50 Hz; the C3 failsafe timeout defaults to 250 ms. On timeout, motors are set to zero and a fresh explicit arm edge is required after link recovery. nRF24 Enhanced ShockBurst ACK/retry is used; application telemetry/ACK payload support is not implemented in this initial firmware. Delivery counters reflect local TX success/failure, not guaranteed end-to-end control execution. PA+LNA and standard module RF performance differ; verify range and antenna placement.
